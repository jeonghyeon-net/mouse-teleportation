# 사용 안내

앱을 응용 프로그램 폴더에 넣고 한 번 실행한 뒤 **Option + Tab**을 누릅니다. 모니터가 두 대면 반대편 중앙으로, 세 대 이상이면 화면 배치 순서의 다음 화면으로 이동합니다. 이동은 창의 활성화나 클릭을 발생시키지 않습니다.

도착 화면의 사각 가장자리에서 안쪽으로 약 64pt 너비의 옅은 푸른빛이 **0.24초** 동안 부드럽게 번졌다 사라집니다. 가는 윤곽선은 없고 화면 가운데는 투명하며 마우스 클릭은 아래 앱으로 전달됩니다. 빠르게 연속 이동하면 이전 효과는 즉시 사라집니다. macOS의 **동작 줄이기**가 켜져 있으면 움직임 없이 더 약한 효과를 0.12초만 표시합니다.

단축키를 누를 때마다 현재 화면 목록을 읽으므로 모니터 연결·해제나 배율 변경 후 재실행할 필요가 없습니다. 전체 화면과 Spaces에서도 같은 전역 단축키를 사용합니다. 다만 보안 입력을 사용하는 앱이나 독점 단축키를 등록한 다른 앱에서는 키 전달이 달라질 수 있습니다.

## 실행 상태와 종료

일반 창이나 메뉴바 아이콘은 없습니다. **활성 상태 보기**에서 `MouseTeleportation`을 검색하면 실행 상태를 확인하거나 종료할 수 있습니다. 커서가 확대되는 짧은 순간에는 같은 실행 파일의 보조 프로세스가 하나 더 나타납니다.

터미널에서는 다음 명령으로 상태를 확인합니다.

```sh
"/Applications/Mouse Teleportation.app/Contents/MacOS/MouseTeleportation" --status
```

`loginItem`이 `enabled`이면 자동 실행 등록이 완료된 상태입니다. `requires-approval`이면 **시스템 설정 → 일반 → 로그인 항목 및 확장 프로그램**에서 허용해 주세요.

## 자동 시작 끄기와 삭제

시스템 설정의 로그인 항목에서 끌 수 있습니다. 앱을 다시 실행해도 사용자가 끈 항목을 자동으로 되살리지 않습니다.

터미널로도 설정할 수 있습니다.

```sh
"/Applications/Mouse Teleportation.app/Contents/MacOS/MouseTeleportation" --disable-login
# 다시 켜기
"/Applications/Mouse Teleportation.app/Contents/MacOS/MouseTeleportation" --enable-login
```

삭제할 때는 먼저 자동 시작을 끄고 활성 상태 보기에서 앱을 종료한 뒤 응용 프로그램 폴더의 앱을 휴지통으로 옮깁니다. 소스 저장소가 있으면 `make uninstall`로 같은 절차를 수행할 수 있습니다.

## 단축키가 동작하지 않을 때

1. 확장 디스플레이가 두 개 이상인지 확인합니다. 미러링은 화면 한 개로 처리합니다.
2. 마우스 버튼을 놓고 Tab을 뗐다 다시 누릅니다.
3. Option + Tab을 사용하는 창 전환 앱 등이 있다면 그 앱의 해당 단축키를 변경합니다.
4. 활성 상태 보기에서 앱 실행 여부를 확인하고 응용 프로그램 폴더에서 다시 실행합니다.

화면 이동에는 접근성 권한이나 입력 모니터링 권한을 요청하지 않습니다. 확대 효과만 동작하지 않으면 `--status`의 `cursorScale`이 숫자인지 확인하고 macOS 버전과 함께 제보해 주세요.
